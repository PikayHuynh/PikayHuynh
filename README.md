## 👨‍💻 About Me

I'm a **Backend Developer** focused on building reliable, maintainable, and production-oriented backend systems with **Go** and **Java/Spring Boot**.

My main interests are in backend engineering fundamentals and the infrastructure around production systems: **API design, databases, concurrency, caching, messaging, distributed systems, observability, and containerization**.

I started my backend journey with **Java and Spring Boot**, and I'm now going deeper into **Go** to strengthen my understanding of concurrency, performance, networking, and backend system fundamentals.

### 🚀 What I Work With

* 🦫 **Go** — HTTP services, concurrency, workers, context, performance
* ☕ **Java / Spring Boot** — backend services, security, REST APIs
* 🌐 **REST APIs** — API design, validation, error handling, authentication
* 🗄️ **PostgreSQL / MySQL** — schema design, transactions, indexing, query optimization
* ⚡ **Redis** — caching, rate limiting, distributed workloads
* 📨 **Kafka / RabbitMQ** — asynchronous processing and messaging
* 📊 **Grafana / Prometheus** — metrics and observability
* 🐳 **Docker / Docker Compose** — containerized development and infrastructure
* 🧪 **Bruno / Postman** — API development and testing
* 🔧 **Git / GitHub / GitLab / Make** — development workflow and automation

### 🌱 Currently Learning

**Go concurrency · System Design · Distributed Systems · PostgreSQL Internals · Database Performance · Networking · Observability · Production Engineering**
